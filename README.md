# Bella-Vista-Oasis-Spa-Group-3
Vista Digital Solutions built the Bella Vista Oasis Spa Reservation Request System (PHP, JS, HTML/CSS, MySQL) for guests and managers. It streamlines bookings, pricing, walk-ins, therapist assignments, and room availability with 30-min cleaning buffers via SMTP and reCAPTCHA; production hosting and setup remain the essential launch needs.
